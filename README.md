# Amazon Sales Dashboard

Power BI dashboard analyzing Amazon sales data — built as a beginner portfolio project.

## Features
- Sales breakdown by product category
- Sales trend over time
- Order status analysis (Shipped, Cancelled, Pending)
- State-wise filtering with slicer
- Sales channel comparison (Amazon.in vs Non-Amazon)
- Business vs Regular customer breakdown

## Tools used
Power BI Desktop, Excel, Kaggle dataset (Amazon Sale Report)
